# PeopleGrove Opportunity Discovery & Tracking

Case-study microsite for a UX design internship project completed through WGU's Applied Learning Capstone (D657), with PeopleGrove as employer partner. Built with Next.js App Router, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run build
```

## Notes

- The final capstone case study PDF is served at `/docs/peoplegrove-case-study-approved.pdf`.
- The Figma CTA links to the prototype file.
- The site copy intentionally avoids implementation, launch, adoption, and metric claims.

## Claim boundaries

- This was a **UX design internship project** completed through WGU's Applied Learning Capstone (D657). PeopleGrove was the **employer partner** — the project was **not commissioned, implemented, or endorsed by PeopleGrove**, and it is not a shipped PeopleGrove product.
- Usability findings come from a **moderated, task-based think-aloud test with three proxy participants (classmates) on a low-fidelity prototype**. Results are **indicative, not conclusive** — they are not field-performance evidence and not real PeopleGrove production-user data.
- Accessibility is described as **WCAG 2.1 AA-aligned**. No formal WCAG conformance audit has been performed. Contrast conformance was not formally measured.
